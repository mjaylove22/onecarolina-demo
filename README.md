# One Carolina Transit — website prototype

Static HTML + compiled Tailwind CSS + vanilla JS. Hosted on GitHub Pages.

## Edit & build
```
npm install          # first time only
npm run build:css    # rebuild assets/css/tailwind.css after changing classes/config
npm run watch:css    # or rebuild automatically while you work
```
`assets/css/tailwind.css` is committed, so GitHub Pages needs no build step.
Preview locally with any static server, e.g. `python -m http.server`.

See `PROJECT-HANDOFF.md` (status/context), `DEV-NOTES.md` (technical to-do),
and `CLIENT-QUESTIONS.md` (what's answered vs. outstanding).
